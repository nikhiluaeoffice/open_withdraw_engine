# SDK Demo Node.js Application

A simple Node.js application demonstrating how to integrate `@reusable-withdraw/sdk` into your backend apps.

## How to Run

1. Open your terminal and change to the `demo-app` directory:
   ```bash
   cd demo-app
   ```

2. Install local SDK dependency:
   ```bash
   npm install
   ```

3. Run the application:
   ```bash
   npm start
   ```

### Optional Environment Variables

You can pass a custom API Secret Key or Backend URL:

```bash
SECRET_KEY="sk_test_your_secret_key" API_BASE_URL="http://localhost:10010" npm start
```
